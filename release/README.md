# Release checklist

This directory is a placeholder for a future release process. A release must
not be cut from the private development snapshot merely because CPU/C tests or
the native build pass.

Before public release, complete:

- copyright and institutional ownership review;
- a project license and required notices;
- dependency and source provenance review;
- sanitized, reproducible evidence;
- contributor, security, and conduct policies;
- a clear statement of which profiles are actually executable.

Before ASF incubation, complete a separate IP clearance, contributor and
governance plan, dependency compatibility review, and ASF community process.
