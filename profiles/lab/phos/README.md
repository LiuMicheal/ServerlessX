# PhoenixOS lab profile

**ID:** `phos_lab`
**Maturity:** private lab reference
**Executable:** no in this bootstrap

The profile describes the separate PhoenixOS/Remoting/Mitosis experiment
environment used by the authors, including the SPD VM and GPU migration work.
It is kept as a map for future integration and for reading the research record.

The bootstrap intentionally does not ship PhoenixOS, PhoenixOS-Remoting,
KRCore, Mitosis, kernel modules, shared libraries, VM images, containers, or
generated patches. A profile link to an upstream project is attribution and a
reproduction lead, not a redistribution license. See the nested
`AGENTS.md`, [provenance/upstreams.json](../../../provenance/upstreams.json), and
[the licensing boundary](../../../provenance/licensing.md).
