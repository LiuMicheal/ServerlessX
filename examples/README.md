# Examples

The first runnable example is the CPU SPD contract simulation exposed through
`./sx run spd --profile cpu`. Native build examples live beside the C/C++ source
under `runtime/` and `native/`. Keep future examples small, deterministic, and
explicit about whether they simulate a transport, compile a backend, or use
hardware.

Do not place model weights, VM images, private endpoints, credentials, or
unreviewed benchmark output in this directory.
